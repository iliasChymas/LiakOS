# iShell system requirements
# This is a cross-language system inventory, not a pip requirements file.
# Do not run `pip install -r requirements.txt`.

# Desktop bar
# AGS v3 with GTK 4 / GJS support
# libastal with AstalTray, AstalWp, AstalBluetooth, and AstalPowerProfiles 0.1
# BlueZ and rfkill for Bluetooth control
# xdg-utils (`xdg-mime`) and GTK 3 (`gtk-launch`) for default-app Wayfire bindings
# Thunar as the LiakOs file manager
# PipeWire and WirePlumber for the bar's per-app audio and device controls
# power-profiles-daemon for the bar's Full performance, Balanced, and Power saver choices
# wf-recorder for screen recording; `slurp` enables optional area selection
# Flameshot plus `xdg-desktop-portal-wlr` for bar screenshots on Wayfire;
# `grim` is used by the example Print keybinding
# `light` for internal backlights, or `ddcutil` for DDC/CI monitor brightness

# Wallpaper slideshow (wallpaper-app/)
# C compiler and pkg-config
# GTK 4.10+ development libraries
# libvips development library
# Pywal16 `wal` command and a Wayland wallpaper setter (swaybg, swww, awww, or
# wbg) for applying a selected image and generating colors

# Application launcher (app-launcher/)
# C compiler and pkg-config
# GTK 4 and GTK 4 Layer Shell development libraries
# JSON-GLib and GIO development libraries
# Wayfire with `ipc` and `ipc-rules` plugins for focusing open applications

# Keybindings editor (keybindings-app/)
# C compiler and pkg-config
# GTK 4 and JSON-GLib development libraries
# Wayfire; the editor reads and updates ~/.config/wayfire.ini (or wayfire/wayfire.ini)

# Startup application manager (autostart-app/)
# C compiler, pkg-config, GTK 4, GIO Unix and JSON-GLib development libraries
# Wayfire; the app saves selected XDG desktop entry Exec commands to [autostart]

# Display setup app (monitor-app/)
# C compiler, pkg-config, GTK 4 and JSON-GLib development libraries
# wlr-randr for reading and applying Wayland output configurations on Wayfire
# The app uses wlr-randr internally; users configure displays from its GTK UI.

# Wallpaper color theming (lpaper and scripts/test-pywal-gtk-colors.sh)
# Pywal16 (`wal`) to set wallpapers and generate ~/.cache/wal/colors.json
# jq to read the Pywal palette
# GTK 3 and GTK 4 runtimes for GTK application colors
# Thunar (GTK 3); the wallpaper script writes a Thunar-specific stylesheet
# qt5ct and qt6ct for Qt 5/Qt 6 palette support outside Plasma/GNOME
# Restart themed applications after applying a wallpaper to load new colors.
# The AGS bar also watches ~/.cache/wal/colors.json.

# Wayfire IPC wrapper (wayfire-ipc.ts)
# Node.js >= 24, which can run the TypeScript wrapper with built-in type stripping
# wf-ipcli 0.1.8 or newer, installed globally with npm
# Python 3 and PyWayfire's `wayfire` package, required by wf-ipcli's helper scripts
# Wayfire >= 0.10 with the `ipc` and `ipc-rules` plugins enabled
# Export WAYFIRE_SOCKET for PyWayfire if it cannot detect the Wayfire socket.

# Optional Wayfire features
# Enable Wayfire's `wsets` plugin if using multiple workspace sets.
